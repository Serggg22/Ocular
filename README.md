# OCULAR

Proyecto de concepto: portfolio web con formato de galería para una estudiante de diseño. Es una prueba de diseño y maquetación, y organiza el trabajo de fotografía y diseño en tres páginas:

- **Sobre mí:** presentación y galería de fotos
- **Detrás de las texturas:** serie fotográfica
- **La doble cara de Madrid:** serie fotográfica

## Características

- Sitio de varias páginas con diseño adaptado a móvil
- Menú de navegación propio para pantallas pequeñas
- Galería y slider de imágenes
- Ojo animado en la portada, hecho con JavaScript

## Tecnologías

HTML, CSS y JavaScript, con Vite como herramienta de desarrollo.

## Scripts

- `npm run dev`: servidor de desarrollo
- `npm run build`: genera la versión final
- `npm run preview`: previsualiza esa versión
